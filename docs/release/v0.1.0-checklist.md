## Why the order is fixed

`@asc-agent/bootstrap` depends on `@asc-agent/runtime` at an **exact** version. If
bootstrap goes to the registry first, the very first `npx --yes @asc-agent/bootstrap@0.1.0`
resolves a dependency that does not exist yet, and the first thing anyone sees is a broken
install.

```text
runtime → verify on the registry → bootstrap → verify → real E2E → tag → release
```

Do not reorder this.


## After publishing

**0.1.0 is immutable.** If the registry end-to-end finds a defect, it is fixed in 0.1.1 —
a published version is never re-published or overwritten, because someone may already have
installed it and a silently different 0.1.0 is worse than a visible 0.1.1.

```text
[ ] defect found after publish → 0.1.1, never a re-publish of 0.1.0
```
