# ASC v0.10.1 — 릴리스 체크리스트 (patch · 0.10.0 acceptance 가 찾은 둘)

정본 경로는 2단계다: `release.yml` (publish) 이후 `release-finalize.yml` (tag·Release).
finalize 는 이 파일의 `## 실행 기록` 섹션이 `main` 에 있어야 돈다.

## 이 릴리스가 싣는 것

```text
#91  asc work issue 가 scmFor(resolved) 로 조립된다 — canonical 선언 workspace 에서 CANONICAL_UNAVAILABLE 이던 자리 (0.10.0 Q-4 FAIL)
     언급 commit 경로 겹침에 경로 경계 꼬리 일치 — 패키지 상대 경로 vs 뿌리 경로 (0.10.0 Q-6a)
```

schema·identity·CLI 표면 변경 없음.

## Gate (publish 전)

```text
[ ] npm run typecheck / build / test          — 1729 / 1728 pass / 0 fail / 1 skip
[ ] npm run release:check                     — 0.10.1 명명·note 섹션·버전 리터럴
[ ] npm run pack:all && npm run smoke
[ ] npm run presentation:check                — 비게이트
[ ] 3-OS CI green on main                     — #91 · release PR
```

## 수동 fallback (워크플로 불능 시에만)

```text
[ ] publish @asc-agent/runtime   → verify on the registry
[ ] publish @asc-agent/bootstrap → verify   (bootstrap 이 runtime 을 exact 로 가리킨다 — 순서 고정)
[ ] published smoke → 인수 → finalize
```
