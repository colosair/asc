# v0.3.0 release checklist

> **In progress — 2026-08-30.** Work Ingress (`asc proceed --work`) + persistent
> distribution 정본화.

This is a procedure, not a script. **Nothing here publishes on its own.** Each
step below is run by a person or an agent the person is watching, and the
recorded result is what happened, not what was hoped.

## What this release carries

- `asc proceed --work <KEY>` — 조사 → 실제 작업 상태 판정 → 계약 도출 → 위임
  범위 안 발급. 새 outcome `WORK_STATE`.
- 판정 안전장치: repo 미관측 시 추천 거부, roleScopes 는 상한이지 boundary 출처가
  아님(`**` 자동 생성 경로 제거), stale tracker 는 생존 산출물 증거에서만.
- `asc setup identity` — 신원 등록·재잠금·게이트 재확인 한 커맨드.
- 보관된 세션 id 재사용 금지(두 state store 공통 계약).
- persistent 배포 정본화 — 전역 설치 smoke, `npm install -g` 문서 핀 검사,
  3단계 실행 모델(zero-install / persistent / development) 문서.

## Order

runtime → verify on the registry → bootstrap → verify → published smoke → tag → release

`@asc-agent/bootstrap` depends on `@asc-agent/runtime` at an **exact** version.

## Gate (before publishing)

```text
[ ] npm test / typecheck / release:check / build / pack:all / smoke  — green
[ ] CI green on main (3 OS)
[ ] npm publish --dry-run   in packages/runtime
[ ] npm publish --dry-run   in packages/bootstrap
```

## Publish

```text
[ ] publish @asc-agent/runtime@0.3.0
        cd packages/runtime && npm publish
[ ] npm view @asc-agent/runtime@0.3.0 version dist.tarball
[ ] publish @asc-agent/bootstrap@0.3.0
        cd packages/bootstrap && npm publish
[ ] npm view @asc-agent/bootstrap@0.3.0 version dependencies
```

## After

```text
[ ] published fresh smoke — npx --yes @asc-agent/bootstrap@0.3.0 setup apply --json (zero state)
[ ] published persistent smoke — npm install -g @asc-agent/runtime@0.3.0 → asc --help / setup status
[ ] git tag v0.3.0 (release commit 을 정확히 가리킬 것) / push tag
[ ] GitHub Release v0.3.0 — draft=false, prerelease=false, tag 일치
```
