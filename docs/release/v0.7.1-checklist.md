# ASC v0.7.1 — 릴리스 체크리스트 (갱신은 새 build 가 한다)

정본 경로는 2단계다: `release.yml` (publish) 이후 `release-finalize.yml` (tag·Release).

## 이 릴리스가 싣는 것

0.7.0 published acceptance 가 잡은 결함 둘. update 가 **교체되기 전 build 로** host 를
갱신하고 성공했다고 적던 것, 그리고 결합 충돌 메시지가 어느 세션과 부딪혔는지 말하지
않던 것.

## Gate (publish 전)

```text
[ ] npm run typecheck / build / test
[ ] npm run release:check
[ ] npm run pack:all && npm run smoke
[ ] npm run presentation:check
```

## 수동 fallback (워크플로 불능 시에만)

```text
[ ] publish @asc-agent/runtime   → verify on the registry
[ ] publish @asc-agent/bootstrap → verify   (bootstrap 이 runtime 을 exact 로 가리킨다 — 순서 고정)
[ ] published smoke → 인수 → finalize
```

## Published acceptance (게시본으로만)

```text
[ ] asc update 로 0.7.0 → 0.7.1
[ ] update 직후 asc host claude probe 가 INSTALLED_CURRENT
[ ] guard hook 이 새 판정을 담고 있다 (commit 문구 PASS · git push BLOCK)
[ ] 같은 Run 이 다른 세션을 집으려 하면 무엇을 놓아야 하는지 말한다
[ ] protected state 변경 0 (관측 기록 제외)
```
