# ASC v0.9.1 — 릴리스 체크리스트 (patch · 0.9.0 follow-through)

정본 경로는 2단계다: `release.yml` (publish) 이후 `release-finalize.yml` (tag·Release).
**이 회차부터 finalize 는 이 파일의 `## 실행 기록` 섹션이 `main` 에 있어야 돈다.**

## 이 릴리스가 싣는 것

0.9.0 published acceptance 와 그 뒤 전수조사가 남긴 목록. 화면에 안 나온 upgrade 보고 한 줄,
파싱되고 버려진 flag 하나, 기준점 없이 돌던 검수 하나, threat model 보다 크게 말하던 문장들,
아무도 부르지 않던 코드 셋, 그리고 tag 가 증거보다 6분 먼저 찍혔던 release 절차.

```text
#86  asc update 가 removed: 를 화면에 넘긴다 (+ CLI 경로 테스트)
     session issue --done 은 쓰기 전 거절 + --criteria 안내 (alias 아님)
     같은 adapter 결합 ≥2 → review/publish/grant issue 가 검수·발급 전에 exit 2 (fail closed, 임의 선택 없음)
     policy.evaluate 계열 · pathInScope · RenderInput.liveness · dist-smoke.mjs 삭제 (production caller 0)
     bootstrap plan 다음 걸음 asc work start · ADVANCED_USAGE deprecated 표기
     executor/skill/npm README/C-01/workspace 주석 — ASC 관리 write 로 범위 축소
     release-finalize: main 의 checklist 에 ## 실행 기록 없으면 거절
```

schema 변경 없음. identity 계약 변경 없음. Guard/F6/셸 interception 부활 없음.

```text
[ ] published smoke → 인수 → finalize
```
