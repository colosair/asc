ASC 0.10.1 fixes two things the published acceptance of 0.10.0 found on the real
workspace, both in the normal path 0.10.0 set out to close. Nothing else moves.

## What changed

**`asc work issue` reads the canonical baseline.** The command built its session runtime
without the SCM port, so on a workspace with a declared canonical source the person's
one-word issue was refused with `CANONICAL_UNAVAILABLE` — the exact step 0.10.0 introduced
to replace the retyped `session issue`. It now assembles the same way `session issue` does.
A source-level test pins that the two share the port.

**Mention overlap understands monorepo paths.** The work-state judgement compares the files
a mentioning commit touched against the paths the work item names. Work items name paths
relative to their package (`tools/devGateway.mjs`); commits record them from the repository
root (`festa-frontend/tools/devGateway.mjs`). Prefix matching alone saw no overlap, so a
genuinely merged work item was left `UNDECIDABLE`. A match on a path boundary at the tail
now counts, and a leading `./` or `/` on the work item's side is ignored.

## Compatibility

- Node 24 or newer, unchanged.
- No schema, identity, Profile or CLI-surface change. Proposals saved by 0.10.0 issue
  unchanged with the fixed command.
- A work item that 0.10.0 judged `UNDECIDABLE (implementation-evidence)` only because of
  the path prefix may now judge `IMPLEMENTED_STALE_TRACKER` — the verdict 0.9.x gave it.

## Verified

- Three-OS CI: typecheck, build, the full suite (1729 tests, 1728 pass / 0 fail / 1
  skipped), release checks, packaging, packaged smoke.
- `asc work issue` end-to-end through the CLI, plus the source-level pin that it takes
  `scmFor(resolved)`.
- Path overlap: a package-relative work-item path against a root-relative commit path.
- Published acceptance on the maintainer's macOS host re-runs the two failed items of the
  0.10.0 record (Q-4 and Q-6a) and is recorded in `docs/release/v0.10.1-checklist.md`
  before the tag.

## Known limitations

Unchanged from 0.10.0: liveness is not observed; resource identity is path-only and two
bindings for one adapter are refused; GitHub has no pre-execution `review()`; closed
proposals are not archived; the three deprecated aliases still answer; Windows is covered
by CI only.
